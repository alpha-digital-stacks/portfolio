
# 📄 Resume - Shadcn UI Resume and Portfolio Template

**Resume** is a **free, open-source, and production-ready resume / portfolio template** built with **Next.js, Tailwind CSS, and shadcn/ui**.

It’s designed for **developers, designers, freelancers, and professionals** who want a modern, fast, and clean personal website to showcase their **experience, skills, and projects**.

If you’re looking for a **high-quality Next.js resume or portfolio template** with modern UI components and excellent performance, this template is a great starting point.

---


## ✨ Key Features

- ⚡ Built with **Next.js** for optimized performance and SEO  
- 🎨 Styled using **Tailwind CSS** for utility-first design  
- 🧩 Includes **shadcn/ui** components for consistent UI/UX  
- 📄 Modern resume layout with clear sections for skills and experience  
- 📱 Fully responsive across all device sizes  
- 🚀 Lightning-fast loading and SEO-focused structure  
- ✏️ Easy to personalize content and visuals  
- ☁️ Ready to deploy on platforms like **Vercel**

----------

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shadcnspace/resume-shadcn-ui-resume-and-portfolio-template.git

```

### 2️⃣ Install Dependencies

```bash
npm install
# or
pnpm install
# or
yarn install

```

### 3️⃣ Run the Development Server

```bash
npm run dev
# or
pnpm dev
# or
yarn dev

```

Open **[http://localhost:3000](http://localhost:3000/)** in your browser to see the result.
